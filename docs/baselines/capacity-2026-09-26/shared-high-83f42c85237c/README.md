This is one Engine, one FULL journal/Redis and one signer per family, with EVM60/OP60/Nitro50/Solana65 offered for360 seconds. The rates came from individual screens, not qualified sustainable maxima.

The cause of each long processing cycle was not isolated by the available logs.
